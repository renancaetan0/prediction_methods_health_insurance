# Health Insurance Pricing: Prediction Methods, Churn Risk and AI Benchmark

This repository contains a reproducible data science case for health insurance
pricing. The project compares classical segmentation, interpretable regression,
formal non-linear model selection and an AI-generated machine learning workflow
on the same public Kaggle dataset.

The analysis is centralized in one notebook:

```text
notebooks/prediction_methods_health_insurance.ipynb
```

## Project Goal

The project studies two different business questions that are often mixed
together in pricing work:

1. **New customers:** estimate future medical expenses and suggest an initial
   premium.
2. **Current customers:** adjust existing premiums while controlling churn risk.

The main contribution is not only to compare predictive metrics such as R2,
RMSE and MAE, but also to translate model outputs into pricing decisions,
expected churn and profit under a Regression Discontinuity Design inspired
churn function.

## Dataset

The dataset used in this project is public data obtained from Kaggle. It
contains real health insurance customer records, but the insurer's identity must
remain confidential.

Main fields:

- `age`
- `gender`
- `bmi`
- `children`
- `discount_eligibility`
- `region`
- `expenses`
- `premium`

The notebook uses a fixed 80/20 split:

- 1,070 customers for training/model selection.
- 268 customers as a holdout set.

## Methods Compared

The notebook compares:

- K-Means clustering as a customer segmentation and cluster-level pricing
  baseline.
- Linear Regression with stepwise feature selection as an interpretable
  baseline.
- A formal model selection workflow inspired by Ljung and Aguirre's System
  Identification methodology for static non-linear systems.
- Candidate model families including Linear Regression, Polynomial Regression,
  Ridge, Lasso, Natural Spline, MLP and Kernel Ridge.
- Random Forest generated by an external AI/vibe-coding workflow using
  cross-validation and hyperparameter tuning.

## Main Findings

For the holdout set of 268 unseen customers:

- Kernel Ridge was selected by the formal methodology before the AI benchmark,
  with holdout RMSE of approximately **R$ 753.18** and R2 of **0.726**.
- The AI-generated Random Forest achieved stronger raw predictive performance,
  with holdout RMSE of approximately **R$ 647.89** and R2 of **0.797**.
- The Random Forest internal validation was optimistic compared with the true
  holdout, reinforcing that cross-validation alone is not enough for business
  deployment.
- K-Means outperformed simple Linear Regression in this dataset, a
  counterintuitive result explained in the notebook by right-skewed expenses,
  non-linear effects, missed interactions and feature-set asymmetry.
- For current customers, predictive models should not be applied blindly as
  repricing tools. The notebook includes a separate no-model premium adjustment
  strategy based on current `premium`, current `expenses` and churn tolerance.

## Business Interpretation

The recommended decision logic is two-track:

- **For new customers:** use the best validated expense prediction model.
  In this experiment, the Random Forest benchmark performs best in raw
  predictive accuracy.
- **For current customers:** use a churn-aware premium adjustment rule instead
  of reusing a new-customer expense model. Leaving current customers without any
  adjustment may also destroy value, especially when some customers generate
  structural losses.
